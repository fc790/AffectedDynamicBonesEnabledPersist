# AffectedDynamicBonesEnabledPersist
这是用于游戏koikatu和koikatsusunshine的插件.
套用hongcha卡的都知道,它用Joan6694DynamicBoneCollider的吸引模式来吸住dick让其不捅到其他地方去.但是你一换衣服或者人物,那么DBC的affected Dynamic dones的勾选列表就会默认全选,然后场景里的所有动骨就都被DBC影响,然后就是一切吸过去.这个插件能通过按F9来保存DBC的affected Dynamic dones的勾选列表快照,你换人物换衣服就会自动还原这个勾选列表,就不会换人物和衣服时那么痛苦了,还有场景加载后会默认执行一次F9.注意,此插件是调用的kkpe的功能实现的,所以要有kkpe并且此插件设置后kkpe的ui界面并不会同步.此点要注意
